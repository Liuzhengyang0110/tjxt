## 2. Jev 余额覆盖核算

2026-10-26 查阅 [TypeSafe 官方模型文档](https://docs.typesafe.ai/models)：Jev 1.13 输入价格为 0.042 美元/百万 token，输出免费；默认每请求上下文上限 64k token。本测试仅一个分类问题，未开启长上下文。

使用每次请求都达到 64,000 输入 token 的保守估算：

`1299 × 64,000 ÷ 1,000,000 × 0.042 = 3.491712 美元`

该估算低于用户报告的 5 美元余额，实际人工短样本通常远小于请求上下文上限。它是按公开标准价及逻辑调用上限计算的估算，不是账户余额核验、真实账单或程序货币硬限额；底层传输重连不可精确观测，其他并发消费也不属于本测试。Jev 不做应用层重试，保持独立调用上限。鉴权、余额/配额、系统性失败或不确定完成状态出现时，停止继续发起。

5 美元针对 Jev 账户；DashScope 使用既有账号单独计费，受本次逻辑调用和执行尝试上限限制。没有真实账单证据时不将逻辑调用减少比例写成费用减少比例。
